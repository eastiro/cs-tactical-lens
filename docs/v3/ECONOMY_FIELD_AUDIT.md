# V3.1 经济字段审计

更新时间：2026-07-16

## 结论

V3.1 的经济标签描述的是**冻结结束时可观测的装备结构与账户余额**，不是队伍的主观购买意图。

分类器使用：

- 装备清单与主武器类别；
- `current_equip_value`；
- 护甲、头盔、拆包器；
- `cash_after_buy`（冻结结束账户余额，存在时）。

分类器不使用：

- `start_cash`；
- `cash_spent`。

## 原因

在真实职业 demo 的冻结结束快照中，`start_cash` 与 `cash_spent` 在少数回合会出现彼此不可能同时成立的组合。例如，`blast-bounty-2026-season-1-finals-parivision-vs-spirit / de_mirage` 第 2 回合，PARIVISION 五人合计 `start_cash = 1400`，但合计 `cash_spent = 17300`。这两个字段不能被当作稳定的消费账本。

它们仍保留在 `economy_snapshots.csv`，供后续解析器或数据源审计；但不得用于经济标签、UI 中的购买结论或战术解释。

## 当前强起口径

`force_buy` 需要同时满足：

1. 未满足全起的装备结构；
2. 至少两把非默认武器；
3. 至少四名选手有冻结结束余额记录，且人均剩余不超过 $800。

因此强起标签置信度最多为“中”：它是基于可观察到的投入和剩余余额的保守描述，而不是对队伍意图的断言。

## UI 约束

经济证据面板可展示装备、装备价值、防具、拆包器、冻结结束余额，以及复用的分类标签/理由；首版不展示 `start_cash` 与 `cash_spent`。
