# V3 范围冻结：Mirage 跨战队证据比较

## 当前决定

V3 第一阶段固定比较 **Team Falcons（karrigan 阵容期）** 与 **Team Spirit（需先确认阵容期）**，地图固定为 **Mirage**。

这不是“谁更喜欢打 A/B”的战术判断器，而是一个带证据边界的描述性比较器：在相同地图、阵营和接触前取样条件下，展示两队的开局结构分布和首次交火时间，并给出比赛数、有效样本数和具体回合索引。

## MVP 做什么

- 选择或固定两支战队与 Mirage；
- 切换 T / CT；
- 并列查看 20 秒接触前人数结构；
- 查看首次交火时间的摘要；
- 显示每队的有效样本数、覆盖比赛数和样本门槛；
- 列出具体比赛、回合号和首次交火时间；点击证据后进入独立的“证据回放”页面，普通“回合复盘”仍保持默认单场 Demo。

## 证据边界

- 每条发现必须带分母、覆盖比赛数和具体回合；
- “重复出现的结构”不等于默认战术；
- 中期站位变化不做队伍意图推断；
- V3.0 初始样本的经济范围曾标记为 `unclassified`；V3.1 仅在有冻结结束快照时补充经济标签，不把缺失数据强行分类；
- Spirit 如果阵容或数据来源不稳定，必须在页面上显示限制，而不是合并成一个无条件的总体。

## 最低样本门槛

- 每队至少 5 场 Mirage；
- 每队至少 30 个 20 秒接触前有效样本；
- 尽量覆盖多个对手，而不是只使用 Falcons vs Spirit 的交手；
- 时间窗口和阵容期必须写入 manifest，不能把不同阵容静默混合。

## 明确不做

- 不做 AI 战术意图判断；
- 不做“哪边更强”的胜率排行榜；
- 不先做经济分类、全地图扩展或第三支战队；
- 不在没有足够样本时生成比较图表。

## V3.0 停止条件

两队各达到最低样本门槛，页面能生成一份带分母和具体回合的跨战队证据报告，并通过完整回归测试；用户可以据此挑出值得复核的回合。达到后先收口，再决定是否做 V3.1（经济分类或第三支战队）。

## 当前状态（2026-07-16）

技术停止条件已满足：Falcons/Spirit 的 T/CT 并列结构、首次交火摘要、比赛覆盖和具体回合证据索引均已接入；证据行可以载入对应本地 bundle 回放。V3.0 当前只剩用户验收，不再自动扩展指标或样本范围。

## V3.1 预备方向：经济状态分层

优先接入可审计的冻结结束装备与现金快照，把回合分为：
`pistol / full_buy / half_buy / force_buy / eco / mixed / unknown`。
目标不是给回合贴一个“正确答案”，而是避免把不同购买状态混在同一张比较表里。

### 分类口径

- **手枪局 `pistol`**：每半场第一回合，单独处理，不算 Eco。
- **全起 `full_buy`**：队伍整体具备步枪或 AWP、护甲和主要道具；不要求每个人手雷买满。
- **半起 `half_buy`**：介于全起和 Eco 之间的中间装备方案，例如 SMG、升级手枪、部分步枪或有限道具；标签描述可见装备结构，不声称队伍是否有意为下一回合留钱。
- **刚枪 `force_buy`**：保守的可观测标签：未达全起、至少有两把非默认武器，且至少四人有冻结结束余额记录并且人均余额不超过 `$800`。它的置信度最多为中，不断言队伍购买意图。
- **经济局 `eco`**：主要目标是保存经济，只购买极少装备；可在展示层细分纯 Eco 与轻 Eco。
- **混合/英雄枪 `mixed`**：一名或少数选手拿枪，其他人处于 Eco/低配，不能强行归为整队半起或刚枪。
- **不确定 `unknown`**：缺少冻结结束快照、现金字段或队伍结构不足时回退。

装备状态和购买意图分开保存。当前只使用冻结结束的装备、防具、装备价值和账户余额；`start_cash` / `cash_spent` 在少数真实 demo 中存在矛盾，保留审计但不用于标签或页面结论。详见 `ECONOMY_FIELD_AUDIT.md`。证据不足时宁可输出 `half_buy` / `mixed` / `unknown`，不从一把步枪或单个选手的余额推断整队意图。

- 经济分类规则、装备快照、现金快照和统计分母由 Codex 设计与验收；
- 核心字段确定后，页面接入、筛选联动、状态提示、表格展示和配套测试可以交给外部 sub-agent；
- 在经济分类稳定前，不急着加入第三支战队或扩展到其他地图。
