十、暗色主题一致性修复
─────────────────────────

  【.streamlit/config.toml】新增 Streamlit 系统级暗色主题：
    base = "dark"
    backgroundColor = "#080b0f"
    secondaryBackgroundColor = "#0e131b"
    textColor = "#e1e7ef"
    primaryColor = "#4da3ff"

    该配置作用于所有 Streamlit 原生组件，包括使用 Glide Data Grid
    渲染的 st.dataframe。网格组件读取 --gdg-* CSS 变量生成画布，
    base="dark" 确保所有默认值都为暗色。

  【Header/Toolbar 白色区域消除】
    header[data-testid="stHeader"]:
      background: transparent !important
      height: 0 !important
      所有直接子元素 hidden
    [data-testid="stToolbar"]: display: none !important
    div[data-testid="stToolbar"]: display: none !important
    section[data-testid="stSidebar"] > div:first-child:
      padding-top 微调以补偿 header 压缩

  【st.dataframe 全面暗色覆盖】
    容器: border/background 同步页面暗色
    Glide Data Grid 变量映射:
      --gdg-bg-cell:        #0c1118
      --gdg-bg-header:      #131a23
      --gdg-border-color:   #1c2330
      --gdg-text-dark:      #e1e7ef
      --gdg-text-medium:    #78869a
      --gdg-text-light:     #4b5769
      --gdg-accent-color:   #4da3ff
      --gdg-font-family:    var(--mono)
    HTML 回退表格:
      thead 深底 #131a23, tbody 交替 #0c1118 / #0e141c
      hover 行高亮 #161e28
      单元格字体 mono 0.75rem
      滚动条暗色处理

十二、1440×900 屏幕实测
──────────────────────────

  回合复盘主区域内容高度约 1243px，900px 视口无法完全容纳，需纵向滚动。

  已做的垂直空间优化（比原始版本减少约 80px）：
    - block-container padding-top: 1.1rem → 0.75rem
    - 比分条 padding/margin 缩减约 15px
    - 控制区 selectbox min-height 压缩约 6px
    - 回合芯片高度降低 6px / 激活态降低 6px
    - 各部分间距微调
    - header 压缩为 height:0（约消除 50px 额外空白）

  雷达图 height 维持在 676px 以保证可读性。
  若需无滚动，需缩小雷达图至约 500px 以下，将严重损害战术复盘核心体验，
  因此当前方案优先保证雷达可读，接受纵向滚动。
